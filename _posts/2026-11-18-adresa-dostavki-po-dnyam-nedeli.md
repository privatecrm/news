**PrivateCRM теперь автоматически распределяет доставки по адресам в зависимости от дня недели.** Достаточно один раз настроить схему в карточке клиента и указать для каждого адреса вид и время доставки — и система учтёт её **при создании заказа, добавлении дней и переносах**.

#### 📍 Как настроить

Карточка клиента → вкладка **«Адреса доставки»** → колонка **«Дни недели»**. Выберите дни недели напротив адресов и нажмите **«Сохранить»**. Это как шаблон: один раз настроили — и схема используется в новых заказах.

#### 🛒 Создание заказа

Создаёте заказ по подписке любым способом — **PrivateCRM** подставит отдельные блоки доставки по вашей схеме из карточки клиента. При копировании заказа блоки будут скопированы из исходного заказа.

Стоимость доставки рассчитается автоматически с учётом всех условий.

#### 📦 Как работают настройки доставки

Напомним, что есть три уровня настроек:

- **Карточка клиента** — здесь задаётся распределение адресов по дням недели. Это шаблон для **новых заказов**.
- **Информация о заказе** — условия **конкретного заказа**. Здесь можно поменять адреса, но само распределение по дням недели не меняется — оно задаётся только в карточке клиента. Эти настройки используются, когда вы добавляете или переносите дни.
- **Календарь доставок** — фактические параметры **конкретных доставок**. У отдельного рациона можно поменять адрес на любой доступный — в том числе на тот, что не распределён по дням недели. Например, если офис закреплён за буднями, дом — за выходными, а у дачи дни недели не назначены, то для конкретного рациона можно выбрать дачу.

⚠️ Поэтому изменение адресов в карточке клиента **не влияет на ранее созданные заказы**, а изменение настроек заказа **не обновляет уже запланированные доставки**. Их можно отредактировать через календарь.

#### 🔌 Для тех, кто использует API

Распределение адресов по дням недели поддерживается и в публичном API. Для работы с несколькими группами доставки используйте атрибут `deliveryGroups`. Прежний формат API сохранён. Подробности — в документации для разработчиков.
